## Deploy to GitHub Pages

1. Create a new repository on GitHub.
2. Upload all files from this project to the repository root.
3. Open the repository's **Settings**.
4. Select **Pages** from the left sidebar.
5. Under **Build and deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
6. Click **Save**.
7. Wait a few minutes for GitHub to publish the site.

## Important

Keep `index.html` and all image/PDF files in the same root folder. File names are case-sensitive, so do not rename the files unless you also update their paths inside `index.html`.
